# Image checklist

Save each file in `assets/images/` with the **exact** filename, as JPEG. Aim for about 1600 px wide and 150–400 KB. Look first at NASA’s Voyager pages (see README), the NASA Image and Video Library (images.nasa.gov) and the JPL Photojournal (photojournal.jpl.nasa.gov). Note each image’s credit; override the default in `data/timeline.js` with `credit:` where it isn’t “NASA/JPL-Caltech”. Label concept art as such.

**Note:** `voyager2_last_images.jpeg` is used by the Voyager 2 timeline (“Final images”, 1989) but is not in the original 31-file table, so there are 32 files.
